## GitHub Pages setup — same simple structure as a portfolio site

Upload these files/folders directly to the repository root:

```text
index.html
assets/
.nojekyll
README.md
```

Then in GitHub:

1. Open the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**.
5. Select folder **/ (root)**.
6. Click **Save**.

No npm, Node.js, build command, or GitHub Actions workflow is required.

Keep `index.html` and the `assets` folder together because all thumbnail images use relative paths.
